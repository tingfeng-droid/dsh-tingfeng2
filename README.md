# dsh-tingfeng2（0.4.5 / schema 29）

DSH 会话检索插件：**旁路持久索引 + 中文双字滑窗召回 + 原文子串兜底**。

## 为什么存在

宿主官方会话检索（FTS5 unicode61）把整句汉字切成一个 token，中文子串查询结构性 0 命中；
实验包索引默认 `:memory:`，重启重建。本插件不改官方任何代码，在旁边自建一份持久索引：

- 中文：索引端与查询端把 CJK 连续段切成双字滑窗，短语匹配 ≡ 子串匹配（真实语料 20 组已知样本召回 100%，根会话与含子代理两范围均经独立真值复核；非任意查询的无条件保证）。
- 兜底：原文另存 `raw_text` 列，FTS 0 命中或查询含标点/符号/单字时走 `instr` 子串精确扫描（有界兜底，不承诺任意形态必中）。
- 持久：自己的 SQLite（`~/.dsh/recall/index.sqlite`），sha256 全文件指纹增量同步，重启不重建（无变更增量实测约 130ms）。
- 排序：bm25 + 时间；单关键词分组聚合下推 SQL（`ftsGroups`），摘录批量预取（窗口函数 top-N/会话）消除 N+1。
- 多词：AND 为**会话级**（同一会话不同文档分别含两词也可命中），OR 并集；默认排除子代理会话与当前会话。
- 跨工作区：默认查全部工作目录，可传 `cwd` 锁定（search/list 同口径归一：小写 + 去尾斜杠）。

## 与官方的关系（防撞设计）

只消费官方基础服务「与后端无关」的读取契约（`listSessions` / `readSession` / `readTitleSnapshots`），
不 import 引擎类、不 fork、不 patch asar、不 override 官方包。官方搜索后端怎么演进都互不干涉；
官方若推出中文分词，移除一条 bundles 条目即可干净退役。

## 工具

| 工具 | 用途 |
|---|---|
| `recall_search` | 关键词检索（中英文、多词 AND/OR、翻页、cwd/类型/时间过滤） |
| `recall_read` | 读会话原文窗口（含被压缩遮蔽的旧内容，fromSeq 分段） |
| `recall_list` | 最近会话清单 |
| `recall_restore` | 回源还原单条被打码事件原文；须显式 `confirmUnmasked=true`，私密标题/子代理/会话头或事件缺失一律失败关闭；不保存原值映射 |

## 隐私（设计借鉴 dsh-palimpsest，MIT）

1. 标题带 `[私密]` / `[no-recall]` / `[不参与回忆]`（含全角/花括号/零宽/方向标记/U+2010 连字符变体）→ 整段会话排除。
2. 标题读不出 / 会话头缺失 / 事件列表缺失 → 失败关闭，按私密处理。
3. 取回历史文本加不可信数据声明 + 每次调用随机 token 边界，防跨会话提示注入。
4. **拒止式（deny-style）凭据打码**，入库与出口同口径（折半角→去零宽→净化代理对→打码）：凡凭据形值一律 `«已打码»` 占位符，**不再按哈希标签/文件名/会话级图像/解码 head 豁免凭据形值**：
   - 已知前缀（sk-/sqap_/ghp_/AKIA/xox/npm_/Bearer）；纯 hex≥32（真 SHA1/SHA256/MD5/commit/校验和同掩，可读性代价经 `recall_restore` 授权回源还原）；JWT 三段形；无点 `eyJ` 单段残片≥20（含点/含 `~` 变体）；版本段粘连 ≥8 位 hex 后缀；中等随机 token；高熵 base64url/base64≥24（混合大小写＋数字≥4＋词形覆盖率<0.7）；
   - 赋值型键值、引号/反引号/弯引号包裹值、裸键值表格形态、未闭合引号/收尾符截断值、整行裸 hex 均按上列凭据形判据打码；敏感键赋值的 hex/base64 值一律打码，排除规则不否决核心打码路径；
   - **通用裸 token 规则（0.4.0）**：散文任意位置（standalone/空格/CJK 紧贴/，；、《》【】。/ASCII 逗号点号括号/换行）的高熵凭据形 run（base62/base64/base64url≥24，非 hex 无前缀亦覆盖）无条件掩，不依赖引号/键/赋值/裸表格句法；precision 由既有排除守卫＋高熵门槛把关；
   - **中文敏感键（0.4.0）**：密码/密钥/口令/令牌/秘钥邻接裸值（冒号/空格表格/等号，无引号）同兜底打码；
   - **非凭据形保留可检索**：UUID v4/v5、纯版本/semver、真路径形态（反斜杠/盘符/扩展名/URL scheme）、词形标识（词段覆盖率≥0.7）、占位符、图像魔数 base64（PNG/JPEG/GIF）与解码可读散文的编码内容；孤立代理对切断的凭据仍打码（净化先于打码，字符类容 U+FFFD）。
5. **无台账回源还原**：索引只存占位符，不建 mask→原值映射表、不落盘新秘密；`recall_restore` 经宿主 `readSession` 实时回源读原事件文本，须显式 `confirmUnmasked=true`；未授权/私密标题/标题读不出/子代理会话/会话头或事件缺失一律失败关闭；还原结果仅当次返回，不写回索引。

## 0.2.0 自污染闭环（路线图1）

本插件自己的 `recall_*`（含 `recall_restore`）tool/call 与 tool/result **不入索引**：否则检索摘录会被后续会话再记录、再入库，
形成回声室＋凭据材料再生（R9-1 根因）＋索引膨胀。tool/result 不带 callId/name（meta 实测为空），
用 `(turn,step)` 配对；仅当该 step 的全部 tool/call 都是 `recall_*` 时才跳过其 result，避免误伤同 step 并行其它工具；
assistant/user message content 数组内的 `tool-call` 块若为 `recall_*` 族，入库前先剔除。

## 回归仪器产品化（路线图2）

- `test/closure.js`：独立宽提取尺（JWT 三段/无点 eyJ/引号 hex/裸 hex/已知前缀/Bearer/PEM/短 base64/长 base64）从源会话提值，
  对索引 FTS 短语＋raw instr 双反查；「完整值整段可检索」＝泄漏，gate 关闭才 exit 0。良性族仅收 occurrence 级确证公开材料
  （SSH 公钥 blob/PNG 图像数据/PGP 公开签名），leaks/material/benign 三桶均做 FTS spot-check；`--strict` 追加凭据材料片段严 gate。
- `test/truth.js`：独立真值召回——oracle 独立重实现入索引范围与 token-aware 匹配（CJK 双字滑窗＋ASCII 整词/子词，标点边界同 unicode61 分隔，不复用 extract/tokenize，避免循环论证），
  subagent id 归一（裸 uuid vs `session-` 前缀同格式），隐私排除按 expected∩hidden/unreadable 交集扣分母；gate 召回≥0.95。
- 两者每次重建必跑；公开完整性哈希/路径/扩展名上下文按非凭据形跳过（与打码口径对齐、独立实现）。

## 已知边界（明示，不承诺）

- **跨帧短语**：多帧 zstd 会话按帧提取，跨帧边界的短语不桥接召回（B11）。
- **打码盲区**：短前缀（低于阈值）/空格分段/中文上下文裸密钥/**短片段（≤13 字符前缀）与带省略号的截断引用**等未知形态可能漏打；对话正文在本地索引中为明文（与官方索引同性质），打码只针对已知凭据形态，纵深防御非保险箱（B3/B7）。完整凭据值（赋值/引号/反引号/转义引号/**裸键值表格**形态）入库与出口均打码且不可检索。**残留短前缀片段本身可检索是事实**（如讨论会话里的截断前缀），认可其为边界的依据是「完整值不可还原＋片段熵低＋此处点名」，而非「片段不可检索」；24-31 位公开完整性哈希（npm block hash 类）、GitHub 公开 node_id 低于凭据阈值放行；若出现裸 base64 整段或裸表格完整值（非截断、可检索）落库则不属本边界，须按缺陷修。
- **占位符**：`YOUR_PASSWORD`/`$VAR`/`<...>`/纯版本串等占位符非真实凭据，放行且可检索是设计，**仅限示例形态，不含真实密钥后缀**；「已打码」字样可检索是标记固有（R2-5）。
- **全角标点**：。、（U+3002/3001）不折半角；其余全角标点（，（）：；等）与全角字母数字折半角；含标点查询走子串精确已覆盖（B14）。
- **跨工作区**：默认跨全部工作目录是有意设计，非缺陷（B8）。
- **AND 语义**：会话级，不承诺跨会话组合（B6/N6）。
- **FTS 普通词碰撞**：NEAR/OR/AND/UNION 等作普通词查询时按 token 低精度碰撞（数据化不构成注入，但精度有限），属产品取舍（B12）。

## 和另外两个插件的联动

三个项目互不依赖，各自可单独安装；放在一起才是一条完整链路，**共同原则只有一条：不生成、不改写，只搬原文。**

```
压缩            dsh-compaction-vcc   压缩时不调模型、不改写一个字，省略处留 (seq N) 指针
  ↓                                  → 上下文变短了，但被省掉的原文随时可回读
记忆            dsh-tingfeng        压缩之后把规则和记忆按原文重新注入
  ↓                                  → 上下文被压缩过，不等于规则被改写过
检索（本项目）   dsh-tingfeng2      跨会话找回原文；凭据形值一律打码，需要时授权回源
```

| 项目 | 解决什么 | 少了它会怎样 |
|---|---|---|
| [`dsh-compaction-vcc`](https://github.com/tingfeng-droid/dsh-compaction-vcc) | 上下文压缩不改写原文 | 压缩后细节被模型"改写"成看似合理的说法，且无法察觉 |
| [`dsh-tingfeng`](https://github.com/tingfeng-droid/dsh-tingfeng) | 压缩后规则与记忆仍是原文 | 长会话里规则被悄悄改写成另一种意思，行为随之漂移 |
| **`dsh-tingfeng2`**（本项目） | 跨会话检索原文 | 过去的结论找不回来，只能靠"我记得" |

一个具体的合用场景：会话跑了一整天、被压缩过十几次之后，你问"上周那条结论当时是怎么定的"——`dsh-compaction-vcc` 保证本次会话里被省掉的原文能回读，`dsh-tingfeng` 保证规则没被改写，本项目保证上周那次会话还能整段搜出来。
