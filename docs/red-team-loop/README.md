## 写作口径

- 只写实测过的数和路径；不确定处标注；不吹"零缺陷"；每篇尽量给可复跑的探针位置。
- 不点名真实凭据，不贴完整密钥；示例值全部合成。
- 引用的轮次、报告节、探针文件名，均可在本项目的提交历史与上一版 `dist/` 基线包中回溯。

## 三篇文章之外的两个伴生项目

这一系列里的验证方法，不只在检索插件上用过。三个项目共享同一条原则：**不生成、不改写，只搬原文。**

- [`dsh-compaction-vcc`](https://github.com/tingfeng-droid/dsh-compaction-vcc) — 压缩时不调用模型、不改写一个字，省略处留 `(seq N)` 指针可回读；本项目里"原文还在不在"的判据就来自它。
- [`dsh-tingfeng`](https://github.com/tingfeng-droid/dsh-tingfeng) — 压缩之后把规则和记忆按原文重新注入，让"上下文被压缩过"不等于"规则被改写过"。

三者互不依赖，可以单独安装；放在一起，才是一条从"压缩"到"记住"再到"找得回来"的完整链路。
